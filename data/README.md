# Lighthill Studio — content files

Edit these TypeScript files and redeploy. The UI maps over them; you should not need to open a React component to change a price, a bio, or a FAQ answer.

| File | What it controls |
| --- | --- |
| `site.ts` | Name, location, email (FormSubmit), Instagram, Peerspace URL, hours |
| `pricing.ts` | In-house packages, rental rates, add-ons |
| `gallery.ts` | Gallery images, captions, categories |
| `studio.ts` | Space copy, features, amenities, specs |
| `team.ts` | Photographer names, titles, bios, portraits |
| `services.ts` | Homepage service cards and marquee |
| `faq.ts` | Accordion questions |

Images live in `public/images/` and `public/brand/`. Keep the paths in these files in sync when you replace a photo.
